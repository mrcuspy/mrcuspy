## Featured project

### 📊 [UEMG Procurement on Databricks](https://github.com/mrcuspy/uemg-compras-databricks)

Data engineering pipeline built on the **Minas Gerais Procurement Portal**: **2.1 million records** processed with a **Medallion architecture** (bronze → silver → gold) and **Unity Catalog** to analyze **R$ 654 million** in purchases made by UEMG (Minas Gerais State University).

**What the analysis shows:** savings achieved in public tenders, the impact of contract amendments, supplier concentration, and how UEMG's prices compare to the rest of the state.

`Databricks` `PySpark` `SQL` `Unity Catalog` `Delta Lake` `Genie`
